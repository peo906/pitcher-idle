# 방치형 투수 (pitcher-idle)

포수 시점에서 공을 받으며 골드를 모으는 웹 방치형 야구 게임.

## 실행

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # dist/ 에 빌드
```

`main` 브랜치에 푸시하면 GitHub Actions가 GitHub Pages로 배포한다.
처음 한 번은 저장소 Settings → Pages → Source를 **GitHub Actions**로 바꿔야 한다.

## 구조

| 경로 | 내용 |
| --- | --- |
| `src/config.js` | 밸런스 숫자와 고정 좌표 (기획서 값). 숫자는 여기서만 고친다 |
| `src/scenes/Stadium.js` | 경기장 화면, 투구 루프, 포구 연출 |
| `src/state.js` | 골드, 자동 저장, 저장 코드, 오프라인 정산 |
| `src/format.js` | 숫자 표시 (K, M, B, T, aa, ab…, 소수점 없음) |
| `src/sound.js` | 임시 합성 효과음, 사운드 켜기/끄기 |
| `public/assets/` | 배경(480×270), 투수 시트, 관중 좌표, 구름, 미트 |

## 1차 범위

투구 → 포구 반응 → 골드 획득. 능력치·경기·진급은 2차.

- 투구 간격 2.25초 → 템포 최대 0.9초 (와인드업 → 공 비행 0.25초 고정 → 반응)
- 스트라이크 50% (×1.1), 볼 (×1.0), 기본 1,000골드 × 1.5 (느려진 템포 보정)
- 자동 저장 30초마다, 탭을 숨기면 접속 종료로 보고 오프라인 정산 (최근 10분 평균 × 50%, 최대 8시간)
- 저장 코드: 설정 → 코드 복사 / 코드로 불러오기

## 에셋 메모

- 배경: GPT 생성 이미지를 480×270 격자로 정리, 하늘은 잘라내 구름 레이어 뒤로
- 투수: PixelLab 64×64 시트, 기준점은 발밑 아래 중앙
- 미트, 공, 효과음은 임시

## 관리자 모드

주소 끝에 `?admin`을 붙여서 열면 상단에 **관리자** 버튼이 생긴다 (이 브라우저에 기억됨, `?noadmin`으로 해제).

- 단계 이동: 초등 1학년 ~ 메이저리그 18단계 바로 이동
- 도구: 골드 지급, 출전 게이지 채우기, 경기 바로 시작, 경기 승리/패배로 끝내기, 능력치 +10 / 초기화
